## 二、用户画像矩阵

### 画像 A：焦虑解谜者（最大流量来源）

| 维度 | 描述 |
|------|------|
| **年龄** | 28-40 岁 |
| **搜索意图** | "how to stop worrying" "anxiety relief without medication" "how to calm my mind" |
| **心理状态** | 长期压力、失眠、职业倦怠、试过心理咨询/药物效果有限 |
| **知识背景** | 零佛道基础，纯粹功能性搜索 |
| **需求** | 快速见效的实操方法，不需要理论体系 |
| **点击偏好** | 列表式文章（"10 ways to..."），短段落，可立刻执行 |
| **转化路径** | 搜索焦虑缓解 → 找到冥想/正念 → 接触佛教概念 → 深度阅读 |

### 画像 B：哲学探索者（最高内容价值）

| 维度 | 描述 |
|------|------|
| **年龄** | 22-35 岁 |
| **搜索意图** | "Buddhism for beginners" "what is Taoism" "Tao Te Ching explained" "Buddhism vs Taoism" |
| **心理状态** | 对现有宗教/世界观不满，寻找替代性解释框架，intellectually curious |

| **核心痛点** | "What is the self?" "What happens after death?" "Why is there suffering?" |
| **点击偏好** | 概念解释型内容，喜欢对比和体系化梳理 |
| **转化路径** | 搜索概念 → 阅读入门文章 → 深入特定流派 → 开始实践 |

|------|------|

| **搜索意图** | "how to meditate correctly" " Buddhist meditation technique" "mindfulness vs concentration" |

## 三、Reddit/论坛高频问题 TOP 10

按出现频率排序：

1. **"If there's no self (anatta), then what gets reborn?"** — 佛教最难的概念，没有之一
2. **"Is Buddhism a religion or a philosophy?"** — 每个初学者必问
3. **"What is the Tao?"** — 道教最高频问题
4. **"Can I be a Buddhist and still believe in God?"** — 兼容性困惑
5. **"How do I start meditating?"** — 实操入口
6. **"Taoism vs Buddhism — what's the difference?"** — 对比需求极高
7. **"Do I need a teacher / can I practice alone?"** — 入门门槛焦虑
8. **"What is wu wei (effortless action)?"** — 道教最被误解的概念
9. **"How does karma work exactly?"** — 因果律的现代困惑
10. **"Why do bad things happen to good people?"** — 永恒的问题

### 内容创作原则

1. **英文优先** — 英文搜索量远大于中文，AdSense CPM 更高
2. **先回答问题，再讲理论** — 用户带着具体问题来的
3. **引用标注** — 所有经典引用标 CBETA/CText 编号，建立权威感
4. **故事驱动** — 佛道寓言改编为现代场景，增加分享率
5. **内链网络** — 概念 → 入门 → 进阶 形成内容闭环，增加 PV
