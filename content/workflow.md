# 内容工作流

## 核心流程

```
你（灵感） → 我（查知识库 + 逻辑推演） → 补充成文 → 入库
```

## 步骤详解

### Step 1: 你提灵感
一个词、一句话、一个概念、一个问题、一幅画面——任何触发点。
> 例："空"、"烦恼"、"道可道"、"为什么说人生是苦"

### Step 2: 我查知识库
在我的训练数据中检索相关佛道知识：经典原文、哲学逻辑、历史脉络、修行方法、现代关联。

### Step 3: 逻辑推演（游戏攻略式）
像游戏攻略一样一步步推导：
- **Level 1**：概念拆解——它究竟是什么？
- **Level 2**：底层逻辑——为什么是这样？
- **Level 3**：进阶心法——如何理解/运用？
- **Level 4**：Boss 战——常见的误解/难点
- **Level 5**：成就奖励——掌握后的收获

### Step 4: 补充成文
推演结果组织成完整文章，存入 `content/zh/`，同步生成英文版。

### Step 5: 入库
更新 `content/plan.md` 状态，标记完成。

## 文章风格

**定位**：现代年轻人能看懂的佛道智慧指南
**语言**：口语化但不失深度，比喻生动，逻辑清晰
**结构**：层层递进，像游戏攻略一样有明确的"关卡"感
**术语**：关键概念保留原文（梵语/拼音）+ 白话解释

## 模板结构

```markdown
---
title: 文章标题
slug: article-slug
category: buddhism|taoism|dialogue|concepts
tags: [标签]
published: true
order: N
---

# 【关卡名称】

**一句话引子**：用现代场景引入。

## 目标

这篇文章要解决什么问题/理解什么概念

## 前置知识

需要了解的基础概念（如果有）

## 正文（关卡攻略式）

### Level 1: 概念拆解
这是什么？核心定义 + 知识库引用

### Level 2: 底层逻辑
为什么成立？经典依据 + 逻辑推演

### Level 3: 进阶心法
更深层的理解维度

### Level 4: Boss 战
常见误解、难点辨析

### Level 5: 成就奖励
掌握后的收获 + 与现代生活的连接

## 参考资料（关卡秘籍）
- 核心经典引用
- 延伸阅读提示
```
