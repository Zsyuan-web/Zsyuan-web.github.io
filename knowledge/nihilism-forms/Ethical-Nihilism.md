# Ethical Nihilism — 道德虚无主义

## Core Question
如果没有客观的道德，为什么要做好人？

## Symptom
一种怀疑：所有道德规范不过是社会建构——权力的工具、进化的程序、文化的条件反射。善恶不是真实的；它们只是我们讲的故事。但如果这是真的，什么能阻止你为所欲为？

## Buddhist Response
佛教不把道德建立在神圣立法者之上——它建立在因果上。"好"不等于遵守规则——它是不对自己和他人造成痛苦的行为方式，因为痛苦有原因，而这些原因可以被理解。业（karma）不是宇宙的审判——它只是因果。你不需要绝对的道德法则才能看到：有些行为导致地狱状态（对你和他人），有些通向自由。

## Taoist Response
道家不规定道德规则——它描述事情如何自然运作。上德不德，是以有德——最高的德不自称德，那就是为什么它"是"德。当你不强迫、不做作地行动，自然的慈悲升起。河流不决定要滋养山谷；它只是流。像水一样。不遵守规则的伦理——是顺道而行。

## Cross-Cultural Mapping
- 尼采：权力意志 → 创造新价值
- 佛教：业 → 因果不是审判
- 道教：上德不德 → 自然的慈悲
