# 夺境 — Seizing Context (Step 1)

## Definition
在给出任何解决方案之前，先把问题用虚无主义的透镜重新呈现。读者的焦虑/困惑/空虚不是个人失败或医学症状——这是和存在本身的虚无打了个照面。

## How It Works
夺境是禅宗的技巧——把读者熟悉的认知框架拆掉，让他直接看到存在的裸机状态。

1. 从读者的具体场景切入（不要从概念开始）
2. 拆掉他用来解释自己处境的框架（"这只是焦虑"、"我只是需要休息"）
3. 让他看到：他的痛苦不是偶然的，是根本性的
4. 不给答案——只给一个不同的看问题的角度

## Why This Comes First
如果直接给答案，读者会把它当成新的安全网抓住。夺境的效果是：让读者发现他一直在用的安全网原来不能保护他，他才能真正接受新的视角。

## Western Parallels
- 尼采：上帝死了，传统价值坍塌——这是夺境的西方版本
- 海德格尔：存在的遗忘——先让人意识到他遗忘了存在

## 与其他两步的关系
- 夺境 → 用工具 → 空空
- 夺境是"拆"，用工具是"用"，空空是"连用工具的我也拆掉"
- 没有夺境，读者会抓住佛道的概念变成新的执著
- 没有空空，读者会停在"我理解了"，而不是真正自由

## Example
用户搜索"how to stop worrying"

夺境的回答：
"你已经试过所有方法——深呼吸、正面思考、接受——都没有用。凌晨三点，你第五次想'为什么我这么焦虑'。也许这不是一个可以用方法解决的问题。也许你的焦虑不是偶然的，它是你一直试图在无常的事物上建立永恒安稳的这个做法的副作用。"
