# 用工具 — Using Tools (Step 2)

## Definition
佛教和道教不是要你信仰的体系——它们是要你使用的工具。

- 佛教提供分析的手术刀：缘起、空性、无我、四圣谛
- 道教提供体验的指南针：无为、自然、水的隐喻

## How It Works
在夺境之后，读者已经看到他的问题不是可以用旧框架解决的。然后我们引入佛道的工具：

1. 佛教的诊断：用缘起/空性来分析他的具体困境
2. 道教的体验：用无为/自然来指出活着的另一种方式

## 为什么需要两个工具
佛教是诊断——它把问题拆开看，让你看到前提是错的。
道教是体验——它指出另一条路，让你感受到另一种活法。

单一工具的问题：
- 只有佛教：停在分析里，变成哲学讨论
- 只有道教：变成生活建议，没有穿透力

## Buddhist Tools
- 缘起（pratītyasamutpāda）：一切是因缘和合，没有独立存在的实体
- 空性（śūnyatā）：一切没有自性，抓取不到
- 无我（anātman）：没有固定的我可以被证明或失去
- 无常（anitya）：一切在变，包括你的痛苦

## Taoist Tools
- 无为（wu-wei）：不违背本性，顺着纹理走
- 自然（ziran）：让一切成为它本来的样子
- 虚舟：愤怒需要一个"故意的对象"
- 庖丁解牛：先找间隙，然后间隙找你，最后你化在间隙里

## 与其他两步的关系
- 夺境 → 用工具 → 空空
- 夺境是"拆"，用工具是"用"，空空是"连工具也放下"
- 如果没有夺境就直接用工具，读者会把它当成新的答案抓住
- 如果没有空空，读者会停在"我用工具处理了我的问题"——工具变成了新的执著

## Example (Continuing from 夺境)
"你的焦虑来自抓取——试图在无常的事物上建立永恒的安稳。这是无明（avidyā）。缘起说：每一个让你焦虑的想法都是条件临时凑在一起的，它们会消失，就像它们出现一样。无为的意思是：你不需要停止焦虑，你只需要不再'对抗'焦虑——你顺着它的纹理，让它流过。"
