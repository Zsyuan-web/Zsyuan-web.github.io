# 缘起（Pratītyasamutpāda）

## Definition
一切事物因缘和合而生，条件变则事物变。没有独立存在的实体。

## 核心命题
缘起是佛教对"存在"的基本诊断。不是"有什么东西存在"，而是"有什么东西发生了"。每一刻的世界都是无数条件临时凑在一起的现象，没有任何一个条件是"本质"，所以没有任何一个存在者是"绝对真实"的。

## 十二因缘
无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死

这是无明（avidyā）如何导致苦的完整链条。无明让我们的认知扭曲，抓取"有"（存在），然后陷入生死的循环。

## 与空（śūnyatā）的关系
缘起即空——因为一切是因缘和合，所以一切没有自性。没有自性，所以是空。不是"空"比"缘起"更真实，而是"缘起"和"空"是同一件事的两个说法。
