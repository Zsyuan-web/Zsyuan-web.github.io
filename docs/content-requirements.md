## 一、写作原则

### 核心原则：先有引文路径，后有推导

写作顺序的根本变化：不是"先写内容，再插引文"，而是"先锁定引文路径，再为每处引文设计推导"。

每一处引文都对应一段完整的逻辑链——从具体场景切入，逐步追问，由浅入深，引文在逻辑链的终点印证读者的判断。不是推着读者走到引文，是读者自己走到那里。

### 核心原则：只描述，不指引

文章的任务是描述真实。让读者在阅读过程中自己得出结论。

不是告诉读者"你应该怎么做"，而是让读者看到"事情是这样的"。

读者读完后的感受应该是"原来是这样"，而不是"我应该这样做"。

### 语气：并肩，不是教导

文章和读者是平等的。你不是在教导一个不懂的人，你是在和一个懂的人交换看法。

人称根据语境灵活使用——抽象论述用"我们"，具体场景描述用"你"，论断性语句强化冲击力可用"你"。不机械，不强制。

### 内容密度：信息量要撑满

一篇文章必须有足够的思维重量。每一个段落都要有新的东西——新的角度、新的证据、新的追问。不能靠空行和过渡句撑篇幅。要做到：删掉任何一句，读者就会漏掉一个关键信息。

逻辑链要求：每个结论必须从前一步推出。不允许跳步。不允许"显然"、"其实"、"也就是说"这类偷懒的连接词代替真正的推导。

### 人文关怀

人文关怀不是"一切都会好起来的"（廉价安慰），也不是冷漠。

人文关怀是：你看到了读者真实的处境，你用准确的语言把它说出来。

好的文章让读者感到：我被认真对待了。不是被安慰，是被看见。

**两种正确写法：**

写法一：承认现实 + 开放
```
明天你大概率还是会困。汇报也许顺利也许不顺利。那些声音还会回来——它们总是回来。没关系。
```

写法二：看到读者正在做的事，并承认它
```
你已经撑了很久了。每天醒来都觉得累，但还是要继续。你没有崩溃，你还在这里。这本身说明了一些东西。
```

### 结尾：拒绝格式化

结尾禁止使用固定句式（如"没什么大不了的"），禁止重复使用与前文相同的收尾方式。每篇文章的结尾必须根据文章自身的走向自然生成，可以停在承认现实里、开放问题里、或者一个未被解决的张力里。结尾是文章的最后一个动作，不是贴上去的标签。

## 二、禁止清单

### 2.1 禁止说教句式

| 禁止 | 问题 |
|------|------|
| "你应该学会放下" | 指示性语气 |
| "你要学会接受" | 指示性语气 |
| "你需要面对自己的情绪" | 指示性语气 |
| "你要改变你的思维方式" | 指示性语气 |
| "你应该这样做" | 直接指示 |

**替代方式：描述结构，让读者自己决定**

```
# 禁止
你应该学会放下。

# 允许
放下不是一个动作。放下是你发现：你一直在抓的那个东西，
在你停止抓的那一刻，它就不在那里了。
不是因为你成功了，是因为你停下来了。
```

### 2.2 禁止鸡汤句式

| 禁止 | 问题 |
|------|------|
| "一切都会好起来的" | 廉价安慰，逃避痛苦 |
| "时间会治愈一切" | 空洞承诺 |
| "你已经很棒了" | 居高临下的空洞赞美 |
| "人生没有过不去的坎" | 虚假希望 |
| "内心强大的人懂得……" | 说教式总结 |
| "人生的智慧在于……" | 说教式总结 |

**替代方式：承认现实，不给虚假的安慰**

```
# 禁止
一切都会好起来的，撑过去就好了。

# 允许
有些事情不会过去。不是所有伤口都会愈合。
但有些事情，在你知道它不会过去之后，反而没那么重要了。
不是释然，是接受。
接受不是接受"会好起来"，是接受"可能不会好起来"。
```

### 2.3 禁止"XX说"权威背书

"XX说"出现在以下情况时是禁止的：

- "佛教说：……，所以你应该……" — 用权威推指示
- "道家认为：……，因此你必须……" — 用权威推指示
- "尼采说：……，所以这证明……" — 用权威替代分析

**"XX说"的正确用法**：只在读者已经认同分析之后，用"这个人也看到了"来强调共鸣，不是用权威来压服。

```
# 禁止（权威背书）
佛教说："诸法不自生。"所以你的焦虑没有固定实体，你应该接受它。

# 允许（共鸣）
你一直在抓一个东西。
抓住的时候，你觉得它很重要。
放开的时候，你发现它还在那里——不是它没消失，
是你又抓住了新的东西。
这个感觉，尼采也有过。
他说：上帝死了，最高价值贬值了，人在废墟上找不到意义。
不是他的问题，是这个问题本身就这样。
```

### 2.4 禁止强行升华

| 禁止 | 问题 |
|------|------|
| "在这个浮躁的时代，我们需要……" | 加不需要的帽子 |
| "在当今社会，越来越多的人……" | 宏大叙事，逃避具体 |
| "可以说，这是一个深刻的道理……" | 强行总结 |

**替代方式：直接进入场景**

### 2.5 禁止概念词典式开头

```
# 禁止
"空（śūnyatā）是佛教哲学中的核心概念，指一切事物没有独立的自性……"

# 允许
凌晨三点十七分。你第五次看手机。
没有什么新的。你还是在翻。
你知道不会有消息。你还是在翻。
这才是问题。
```

### 2.6 禁止章节编号

不能用"一、二、三"、"第一部分"、"1. 2. 3."。用空行和横线分节，论证逻辑驱动阅读节奏。

### 2.7 禁止对话式写作

不要用"你问：……  XX说：……"这种对话格式。这种格式预设了一个"正确的答案"，让文章变成了一种变相的说教。

```
# 禁止
你问：理解了空之后，然后呢？空空说：连"然后呢"这个问题也空掉。

# 允许
"然后呢"这个问题本身建立在一个假设上：
应该有一个"之后"，在那个"之后"里，一切都会清晰。
但空的意思是：这个假设从来没有成立过。
你不需要等到"之后"才能停止。
现在就可以停止。
```

## 三、三步骤框架

三个写作动作：夺境、用工具、空空。三个动作可以自由组合，也可以只用其中一个。

### 夺境

**目的：** 让读者瞬间看到自己处境的结构。不是告诉他们应该怎么做，是让他们看到自己在哪里。

**写法：**
- 非常短。一段话，几句话。
- 直接指出读者假设中的裂缝。
- 不解释，不铺垫，不说教。

**示例：**

```
凌晨三点。你睡不着。你在想：是不是我哪里做错了？
但这不是失眠的问题。
问题是：你一直在想"如果当时那样做就好了"。
这个"如果"是永远填不满的。
无论你做了多少次选择，每次回头，都会有新的"如果"。
你在为一件已经结束的事情，惩罚现在的自己。
```

**夺境后的过渡：** 夺境段落结束后，不要出现过渡句。直接用设问句转向分析：

```
# 禁止（强行过渡）
这就是为什么你总是睡不着。那么，焦虑到底是从哪来的呢？

# 允许（设问转向）
好。这份用来控制的"排练"，它自己从哪来的？
```

### 用工具

**目的：** 用佛道的分析框架，把问题拆开。让读者看到问题背后的结构。

**写法：**
- 一步一步来。每个结论从前一步推出。
- 不跳跃，不强行升华。
- 不说"你应该"。只是描述结构。

**逻辑链要求：** 每一步必须有前一步推出。不允许跳步。

逻辑链示例（焦虑文章）：
```
① 你在排练（观察到的现象）
② 这是控制（概念命名）
③ 控制需要"有一个在因果链外面的人"（深层假设）
④ 这个假设不成立（龙树：缘起）
⑤ 所以排练这个动作本身是条件推出来的（结论）
```

**概念引入时机：** 概念名称（如"缘起"、"无我"）必须在分析进行到一半时引入，不是在段首摆出来：

```
# 禁止（概念词典式引入）
缘起是佛教的核心概念，指一切事物都是条件凑合而成的。

# 允许（分析到一半引入）
没有一个东西是自己产生自己的。也没有一个东西是被某个独立的"他者"单独产生的。一切都是条件堆出来的。佛家管这个叫缘起。
```

**示例：**

```
你抓一个东西，希望它稳定。
但一切都在变。你抓的那个东西也在变。
这就是为什么你抓了很久，最后还是落空。
不是因为你不够努力，是因为"抓"这个动作本身就是这样：
它让你抓住的东西变成你的全部，然后当它消失的时候，你失去一切。
佛教叫这个：缘起。无常。有条件的存在的根本不满足性。
道家叫这个：抓着不放，是逆道而行。
不是批评，是描述。
```

### 空空

**目的：** 指向出口，但不让读者感到被推出去。

**写法：**
- 点到为止。不强求读者"到达"。
- 停在开放问题里，或者停在承认现实里。
- 不给"一切都会好的"。

**示例：**

```
你可能会想：那我现在该怎么做？
这个问题不需要回答。
因为"该怎么做"预设了有一个正确的做法在等着。
但如果你已经在抓那个稳定的东西，现在停下来就够了。
不是得到什么，是看到一直在抓的那个东西，然后放手。
放手不是成功，是停止。
停止够了。
```

## 四、引文规范

### 4.1 引文职责（两种）

| 职责 | 写法 | 示例 |
|------|------|------|
| **印证** | 分析走到某处读者已有共鸣，引文来印证 | 分析"找到就死"后，引用《中论》印证 |
| **升华** | 具体分析触及浅层，引文带出更深维度 | 追问"为什么停不下来"，引用《心经》点出空性 |

### 4.2 引文前置要求

每处引用前必须有一段自然推导（举例或分析），让读者自己走到引文边界。不是推着读者走，是读者自己走到那里。引文的功能是"你也看到了"，不是"所以你应该……"。

禁止：直接丢出引文句子，没有引导段落。
允许：先有3-5句分析/举例，让读者产生共鸣，再引出引文。

### 4.3 引文分布

引文均匀分布在文章中，禁止堆在结尾。每篇引文数量在规划阶段确定（参考 workflow-generation.html Step 1）。

### 4.4 引文递进

每处引文之间必须层层递进（印证→深化→升维→收尾），禁止同一层面重复。

### 4.5 格式

引文和翻译都用 `>` blockquote 包裹，整体是一个连续块：

```
> 原文（不加引号）
> ——《出处》
>
> 翻译：场景化翻译，口语化、3句以内，把古典文本翻译成读者当前正在经历的情境
```

格式要求：
- 原文不加引号，直接跟在 `>` 后
- 出处单独一行，用 `——《出处》` 格式
- 翻译前空一行，与原文区分
- 翻译正文也要加 `>`，保持视觉统一

### 4.6 位置

在读者已经认同分析之后出现。不是为了引出观点，是为了印证他们的判断。

### 4.7 数量

每篇文章至少一处 CBETA 或 CText 引文。实际数量由规划阶段确定。

### 4.8 禁止事项

- 禁止在引文前写"这说明什么"、"所以"、"因为"等推论性语句
- 禁止在引文前写"引用xxx的话来说"等目的性表述
- 禁止连着出现两处引文（引文之间必须有分析/举例段落）
- 禁止同一层面重复引用的核心观点

```
原文（不加引号，直接段落引出）
——《出处》

翻译（凌晨三点的人话）：口语化、场景化，3句以内
```

场景化翻译的要求：把古典文本翻译成"凌晨三点的人话"——用读者当前正在经历的情境来解释概念。原文 + 场景化翻译缺一不可。

### 位置

在读者已经认同分析之后出现。不是为了引出观点，是为了印证他们的判断。

**顺序：分析先行 → 读者认同 → 引文印证**

### 示例

```
诸法不自生，亦不从他生，不共不无因，是故知无生。
——《中论》卷第一

翻译：没有东西是自己长出来的，也没有东西是被什么外力凭空创造出来的。
一切是条件凑合——条件到了，出现了；条件变了，消失了。
不是因为你做错了什么，它才消失。
是因为它本来就是条件凑合的结果，从来就不是一个能被你抓住的"东西"。
```

## 五、翻译原则

**英文版是翻译，中文版是定稿。** 写作时以英文读者为最终对象，中文版用来推敲逻辑和引文。

翻译标准：信（内容准确）、达（流畅自然）、雅（有文采）。

| 维度 | 中文版（定稿） | 英文版（翻译） |
|------|--------|--------|
| 目的 | 组织思路、确认引文 | 给海外用户阅读 |
| 读者 | 中文读者 | 英文读者（零文化背景） |
| 写作时假设 | 海外用户 | 海外用户 |
| 引文来源 | CBETA/CText | 保留原文，需桥接处加注释 |
| 参照框架 | 直接用佛道概念，嵌西哲 | 同中文版，桥接保留 |
| 解释方式 | 为零背景读者解释 | 同中文版 |

**写作流程：**
1. 以英文读者为最终对象，用中文写文章
2. 逻辑链、引文位置、桥接方式均按英文读者需求设计
3. 中文版通过审查后，逐段翻译为英文
4. 翻译时保持"信达雅"——内容准确、流畅自然、有哲学散文质感

**桥接要求：** 中文版写作时已假设读者对中国文化零背景，桥接在写作时已完成，翻译时直接保留。

## 六、自检清单

写作后逐项检查：

```
[ ] 没有"你应该"、"你要学会"、"你需要"
[ ] 没有"一切都会好的"、"你已经很棒了"
[ ] 没有偷懒连接词（显然、其实、也就是说、"这说明什么"）
[ ] 没有模式化开头（"凌晨三点"）
[ ] 引文在读者认同之后，不在开头
[ ] 每处引用前有一段自然推导，不是直接丢句子
[ ] 引文之间有分析/举例段落，不是连着出现两处引文
[ ] 引文之间层层递进，没有同一层面重复
[ ] 没有用"XX说"来替代自己的分析
[ ] 没有强行升华："在这个浮躁的时代……"
[ ] 没有概念词典式开头
[ ] 没有章节编号
[ ] 没有"你问：……XX说：……"的对话格式
[ ] 结尾停在承认现实里，或者开放问题里，不给答案
[ ] 逻辑链完整，每一步从前一步推出
[ ] 标题像朋友发消息，不学术不鸡汤
[ ] 用"我们"而不是"你"（大多数情况下）
[ ] 段落信息量饱满，没有用废话撑篇幅
```

**扩展检查：**

```
[ ] 没有过渡句，分析段之间直接用设问句连接
[ ] 每个概念都在分析进行到一半时引入，不在段首
[ ] 引文有原文 + 场景化翻译
[ ] 中文版不依赖西方哲学解释，英文版需要西哲桥接
```

**内容密度检查：**

```
[ ] 段落信息量饱满，没有用空行或废话撑篇幅
[ ] 每个结论有前一步推导，不跳步
[ ] 没有"显然"、"其实"、"也就是说"等偷懒连接词
[ ] 结尾不是贴上去的标签，根据文章自身走向自然生成
[ ] 结尾与前文收尾方式不重复
[ ] 抽象概念有具体场景/案例落地，不是飘在空中的概念定义
```
